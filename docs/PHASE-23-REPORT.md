# Phase 23 — cPanel / self-hosted export

The supported deployment paths are documented as Node.js-capable cPanel and VPS/cloud. The guide explicitly rejects PHP-only hosting and GitHub Pages for this backend, covers configurable domains and subdomains, SSL, database limitations, environment secrets, private storage, cron/background work, supervised processes, transactional email, backups, releases, and rollback.

No production infrastructure or DNS is claimed to be active; those require operator access and provider credentials.
