# Phase 16 — Localisation

Phase 16 establishes a reviewed, fallback-safe localisation architecture.

## Delivered

- Central translation resources and interpolation helper.
- React localisation provider, persistent language preference and reusable selector.
- Reviewed English default resources for the shared application shell, authentication, navigation, dashboard, roles and modules.
- Language registry prepared for English, isiZulu, isiXhosa, Sesotho, Setswana, Afrikaans, Sepedi, Tshivenda, siSwati and isiNdebele.
- Clear review-pending status and automatic English fallback for languages without approved translations.
- HTML language metadata updates when a user changes their preference.

No machine-generated placeholder translations have been inserted. Additional dictionaries can be added after review by fluent language specialists, without changing application components.
