# Phase 18 — Native Mobile Preparation

- Capacitor wrapper configuration preserves the shared React/API business logic.
- Android and iOS permission templates cover push, location, camera and file selection with purpose text.
- HTTPS and `hydraworks://` deep-link architecture is defined with untrusted-host rejection.
- Shared HYDRA icon and splash colours are ready for official native asset generation.
- Native release instructions cover secure APNs/Firebase credentials, signing, sync and platform builds.

Native packages and generated platform projects are intentionally deferred to a controlled release change so dependency versions, signing teams and bundle identifiers can be approved. No app-store publication is claimed.
